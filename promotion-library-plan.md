# Promotion Library — Implementation Plan

## Overview

**Goal:** Allow authenticated vendors to save, view, load and delete promotional
messages generated by Promo Studio, persisted in SQLite across sessions.

**Scope:**
- `saved_promotions` table + one index in `vendor_users.db` inside `init_auth_db()`.
- Five DB helper functions.
- Three targeted edits in `app.py` (sign-out block, Promo Studio action row, library expander).
- Focused tests in `tests/test_promotion_library.py`.

**Non-goals:** No Granite/RAG/prompt changes, no scheduling, no social publishing,
no redesign, no new dependencies.

---

## Current Promotion Data Structure

| Session-state key | Contents |
|---|---|
| `promo_result` | Generated promotion text (str) |
| `promo_settings` | `{"occasion": str, "platform": str, "tone": str}` |

---

## Database Schema

```sql
CREATE TABLE IF NOT EXISTS saved_promotions (
    id         INTEGER PRIMARY KEY,
    email      TEXT NOT NULL REFERENCES users(email) ON DELETE CASCADE,
    occasion   TEXT NOT NULL DEFAULT '',
    platform   TEXT NOT NULL DEFAULT '',
    tone       TEXT NOT NULL DEFAULT '',
    content    TEXT NOT NULL,
    created_at TEXT NOT NULL DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX IF NOT EXISTS idx_saved_promotions_email
    ON saved_promotions(email);
```

## DB Helper Functions

| Function | Signature | Purpose |
|---|---|---|
| `save_promotion` | `(email, occasion, platform, tone, content) -> int` | INSERT; return id |
| `load_saved_promotions` | `(email, limit=10) -> list[dict]` | Newest-first list |
| `load_promotion_by_id` | `(promo_id, email) -> dict \| None` | Full row; ownership enforced in SQL (WHERE id=? AND email=?) |
| `get_promotion_owner` | `(promo_id) -> str \| None` | Ownership lookup |
| `delete_promotion` | `(promo_id, email) -> bool` | DELETE WHERE id=? AND email=?; True if deleted |

## Safeguards Implemented

| Safeguard | Implementation |
|---|---|
| Ownership in SQL | `load_promotion_by_id` uses `WHERE id=? AND email=?` — no separate ownership check |
| No empty saves | `if _promo_content.strip():` guard before calling `save_promotion` |
| Duplicate-save prevention | Per-content hash key `_promo_saved_{hash(content)}` in session state; shows "Saved!" instead of button on repeat render |
| Load populates both keys | Sets `promo_result` and `promo_settings`; no Granite call |
| Delete enforced at SQL level | `DELETE WHERE id=? AND email=?`; wrong owner → 0 rows → `False` |
| `promo_settings` cleared on sign-out | Added to sign-out block |
