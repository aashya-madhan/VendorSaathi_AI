VendorSaathi AI — Business Profile validation update

Files included:
- app.py
- prompts.py
- business_profile_validation.py
- test_business_profile_validation.py

Install:
1. Back up your current app.py and prompts.py.
2. Replace app.py and prompts.py with the supplied versions.
3. Add business_profile_validation.py to the project root, beside app.py.
4. Copy test_business_profile_validation.py into your tests/ folder.
5. Run: python -m pytest -q
6. Restart Streamlit and generate the Rocky Textiles profile again.

The update preserves the existing profile form, saved business data, and download
workflow. A generated profile is displayed/downloadable only when validation passes.
A rejected draft is not saved in session state or shown.

The validator is deterministic and phrase-based; it is a safeguard, not a semantic
fact checker. Review generated content before publishing.
